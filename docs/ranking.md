# Ranking e certificacao

O ranking deve motivar sem virar corrida vazia.

## Eventos que podem gerar XP

- Primeiro PR aprovado.
- Pipeline corrigido.
- Testes adicionados.
- Dashboard criado.
- Alerta configurado.
- Mensagem publicada e consumida.
- Incidente simulado resolvido.

## Certificacao

A certificacao pode ser gerada por GitHub Actions quando a pessoa atinge criterios minimos:

- Trilhas concluidas.
- Evidencias anexadas.
- Score de qualidade minimo.
- Revisao aprovada.

Assim, o certificado representa pratica verificavel.
