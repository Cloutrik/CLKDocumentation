# CLOUTRIK Docs

A CLOUTRIK e uma comunidade de treino para aprender engenharia moderna fazendo.

O nome vem da ideia de **cloud tricks**: truques de nuvem, desafios e praticas pequenas que ajudam a dominar projetos grandes com Git, CI/CD, observabilidade, mensageria, microservicos e qualidade comprovada por automacoes.

## Como funciona

Cada participante evolui por evidencias:

- Pull request revisado.
- Pipeline aprovado.
- Testes e coverage registrados.
- Servico com healthcheck.
- Logs, metricas e alertas configurados.
- Evento publicado em fluxo de mensageria.

Ranking e XP aparecem depois da qualidade. A pontuacao existe para motivar, mas a prova vem dos artefatos gerados no GitHub.

## Primeiras trilhas

1. Aprender as regras de commit e branch.
2. Abrir o primeiro PR.
3. Passar pelos gates de qualidade.
4. Publicar um servico simples.
5. Adicionar observabilidade.
6. Participar do ranking semanal.
