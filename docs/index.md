# CLOUTRIK Docs

Bem-vindo ao portal de documentação da CLOUTRIK.

Aqui ficam os guias para treinar engenharia moderna com **cloud tricks**: desafios praticos de Git, CI/CD, observabilidade, mensageria, microservicos, qualidade e ranking por evidencia.

## Jornada rapida

- Comece pelo guia inicial.
- Entenda os criterios de qualidade.
- Pratique commits, PRs e CI/CD.
- Avance para observabilidade, mensageria e microservicos.
- Use o ranking como motivacao, nao como atalho.
